SeedSense runs on phones, tablets, and in a browser. The same account works
everywhere, and your work syncs between them.

## Which device to use where

**Tablet** is the best device in the field. The trial layout and evaluation
screens are built for the extra width, and scoring a full plot takes far fewer
taps.

**Phone** works well for checking today's tasks and recording quick
observations.

**Browser** is best at a desk — building trials, bulk-adding varieties, and
reviewing results.

<Callout variant="warning">
  Install the app before you leave for a site with no signal. The browser
  version needs a connection to load the first time.
</Callout>
