The evaluation grade is your verdict on the variety, in two or three words. The
trait scores describe what you saw; the grade says what to do about it.

**You pick exactly one.** There is no way to mark a variety both *Recommended*
and *Retrial* — if the answer is genuinely both, that belongs in the conclusion
text.

## The eleven grades

| Grade | Meaning |
| --- | --- |
| Check Variety | The standard everything else in this trial is measured against. |
| Field Variety | What the grower is already planting on this ground. |
| Advance from Screening | Promising — move it to the next stage of testing. |
| Drop from Screening | Screened and not worth advancing. |
| Recommended | Performed well enough to put in front of a grower. |
| Possible Alternative | Not the first choice, but a real option if the first choice fails. |
| May Work Elsewhere | Wrong for this location; worth trying in a different one. |
| Not Recommended | Did not perform here. |
| Drop from Trialing | Stop testing it altogether. |
| Retrial | Inconclusive. Run it again before deciding. |
| Unable to Evaluate | Nothing to judge — see below. |

*Check Variety* and *Field Variety* are often the same plant, and a trial
variety can be flagged as both when you
[add it to the trial](/trials/assign-varieties-to-a-trial). The grade only lets
you name one of the two, so pick whichever role you actually want the report to
show.

## Unable to Evaluate

This is the grade for a plot that was run over by a tractor, sprayed off, or
otherwise never gave you anything to look at. It is the only grade that relaxes
the required fields.

| Field | Normally | With Unable to Evaluate |
| --- | --- | --- |
| Score | Required | Required |
| Evaluation grade | Required | Required |
| Planting date | Required | Required |
| Maturity date | Required | Optional — becomes an estimate if you enter one |
| Pros | Required | Optional |
| Cons | Required | Optional |
| Conclusion | Required | Optional |

A score is still required, so give it a 1 and say why in the conclusion if you
have one. That keeps the plot in the record as a known loss rather than a gap
somebody has to chase later.

## Grades are a judgement

The app does not compute a grade from the trait scores. A person sets it, using
the scores as evidence. That is deliberate — a variety can score well on every
trait and still be wrong for a market, and *May Work Elsewhere* exists precisely
so you can say so.

<Callout variant="note">
  Grades appear in colour throughout the app, but always alongside the label.
  You never have to read a grade from colour alone.
</Callout>
