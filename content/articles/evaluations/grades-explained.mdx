A grade is the decision a trial leads to. Trait scores describe what you saw; a
grade says what to do about it.

| Grade | Meaning |
| --- | --- |
| Recommended | Performed well enough to go commercial. |
| Advance | Promising — move it to the next stage of testing. |
| Retrial | Inconclusive. Run it again before deciding. |
| Not recommended | Did not perform. Drop it. |
| Check variety | The commercial standard everything else is measured against. |
| Unknown | No grade set yet. |

## Grades are a judgement

The app does not compute grades from trait scores. A person sets them, using the
scores as evidence. That is deliberate — a variety can score well on every trait
and still be wrong for a market.

<Callout variant="note">
  Grades appear in colour throughout the app, but always alongside the label.
  You never have to read a grade from colour alone.
</Callout>
