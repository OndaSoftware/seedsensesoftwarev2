The layout records where each variety physically sits. Getting it right means
evaluators can walk the trial in order instead of hunting for entries.

## Building the layout

Set your rows and plots, then place varieties into them. The layout mirrors how
you actually planted, so build it from your planting plan rather than
alphabetically.

## The map in the field

The map view shows plots with their task colors, so an evaluator can see at a
glance what still needs scoring. Tapping a plot opens that variety's evaluation
directly.

<Callout variant="tip">
  Build the layout before planting day if you can. Doing it afterwards from
  memory is where most placement errors come from.
</Callout>
